# Shayan Command Center — V1

First milestone of the larger personal command-center app.

V1 contains one Home-screen capability card:
- Portfolio Dashboard
- Real reachability health check
- LIVE/OFFLINE state
- Last checked time
- View Details opens the existing production dashboard

Existing dashboard:
https://shayan263.github.io/Shayan_Profile/admin.html

The existing dashboard code is not rewritten. No GitHub commits, production changes, or test analytics events are required by this starter.

An installable iOS app must be compiled and signed using Apple tooling or a cloud macOS build/signing service.
